Technischer Aufbau der Website

Die Website besteht aus statischen Dateien. Es gibt keine Serverfunktion, die Eingaben entgegennimmt oder Daten speichert. An der Bereitstellung sind drei Anbieter beteiligt, von denen nur einer Daten von Besuchern verarbeitet.

Quellcode: GitHub

Der Quellcode der Website liegt in einem Repository bei GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. GitHub wird nur für die Entwicklung genutzt. Beim Besuch der Website wird keine Verbindung zu GitHub aufgebaut, und GitHub erhält keine Daten von Besuchern.

Auslieferung: Vercel

Die Dateien werden von Vercel Inc., 440 N Barranca Ave #4133, Covina, CA 91723, USA, über dessen Content Delivery Network ausgeliefert. Ein Content Delivery Network hält Kopien der Dateien an mehreren Standorten weltweit vor und beantwortet eine Anfrage von dem Standort, der dem Besucher am nächsten liegt. Das kann ein Standort außerhalb der Europäischen Union sein. Die Website wird also nicht an einem festen Ort in Deutschland gehostet.

Bei jedem Abruf verarbeitet Vercel die Daten, die der Browser technisch übermittelt: IP-Adresse, Zeitpunkt des Abrufs, aufgerufene Adresse, übertragene Datenmenge und Browser-Kennung. Diese Daten sind für die Auslieferung der Seite und die Abwehr von Angriffen erforderlich. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. [Im Vercel-Dashboard prüfen und hier eintragen: ob und wie lange Zugriffsprotokolle gespeichert werden, und ob Vercel Analytics oder Speed Insights deaktiviert sind.]

Mit Vercel besteht ein Auftragsverarbeitungsvertrag nach Art. 28 DSGVO. Die Übermittlung in die USA stützt sich auf [Prüfen: das EU-US Data Privacy Framework, sofern Vercel dort zertifiziert ist, sonst die EU-Standardvertragsklauseln].

Domain und Namensauflösung: Squarespace

Die Domain gutmannholding.com ist bei Squarespace registriert [Prüfen: Squarespace Ireland Ltd., Dublin, oder Squarespace, Inc., New York, USA; die Vertragspartei steht im Squarespace-Konto], die Nameserver werden von Squarespace betrieben. Bei der Namensauflösung erhält der Nameserver die Anfrage des vom Besucher genutzten DNS-Resolvers, in der Regel ohne die IP-Adresse des Besuchers selbst. Inhalte der Website laufen nicht über Squarespace. [Prüfen, sobald die Domain auf Vercel zeigt: Bis dahin liefert Squarespace unter gutmannholding.com eine eigene Platzhalterseite aus, die Cookies setzt. Diese Erklärung gilt für die Website in diesem Repository.]

Was diese Website nicht tut

Beim Aufruf lädt der Browser ausschließlich Dateien dieser Website über das oben beschriebene Netz von Vercel. Es gibt keine Verbindung zu anderen Servern. Im Einzelnen:

  • Es werden keine Cookies gesetzt, weder eigene noch fremde.
  • Es gibt keine Web-Analyse und kein Tracking.
  • Es gibt keine Einbettungen von Drittanbietern.
  • Es werden keine Schriften von Drittservern geladen.
  • Es wird kein JavaScript ausgeführt, weder eigenes noch fremdes.
  • Es gibt kein Kontaktformular. Kontakt ist nur per E-Mail und Telefon möglich.

Schriftarten

Die Website verwendet ausschließlich Schriften, die auf dem Endgerät des Besuchers vorhanden sind. Es werden keine Schriften von externen Servern nachgeladen. Damit findet auch keine Übermittlung der IP-Adresse an einen Schriftanbieter statt.
